- [Show HN: Screen memory without screenshots, just text to Markdown](https://github.com/dragthelake/ambient-context) (Hacker News)

- [Bookshelf – Self-hosted eBook library that runs on object storage](https://github.com/murerkinn/bookshelf) (Hacker News)
  开源自托管电子书库，基于对象存储运行，适合个人或团队搭建私有书库。部署成本低，结合 S3 兼容存储即可使用，是替代商业电子书服务的实用方案。

- [Walgit – a Git server that is one binary in front of an object store](https://github.com/tobi/walgit) (Hacker News)
  极简 Git 服务器，单个二进制文件前置对象存储即可运行。适合需要轻量自托管 Git 服务的团队，降低运维复杂度，同时保持数据存储的弹性和低成本。

- [Show HN: A BASIC interpreter that boots on UEFI machines](https://tarjan.itch.io/thoreaubasic) (Hacker News)
